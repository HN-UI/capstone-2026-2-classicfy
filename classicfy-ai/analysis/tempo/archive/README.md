# 기존 10작품 Tempo 분석 자료

새 단일 그래프 예시를 만들기 전의 다중 패널 그림과 요약 CSV다. 파일 내용은 보존했다.
처음 읽을 때는 [현재 Tempo 안내](../README.md)의 실제 작품 예시를 먼저 본다.

- [10개 대표 작품의 중앙 Tempo 곡선](tempo_score_relative_contours_10_pieces.png)
- [악보 기준·동료 기준 비교: 세 패널](tempo_score_vs_peer_reference.png)
- [기존 10작품 요약](tempo_reference_summary_10_pieces.csv)

이 자료는 기존 산출물이며 전용 재생성 스크립트가 현재 저장소에 없다.
새 `scripts/validate_tempo.py`는 기존 Tempo 추출 API로 단일 작품의 새로운 그림을 생성한다.
